🎵 Sky Music

Sky Music is a music browsing web application built with React, Redux Toolkit, and Vite.
It allows users to search music albums, mark favorites, and explore music collections with a clean UI and smooth animations.

**Features**
Search music albums by album or artist
Add to favorites and manage your favorite list
Modern UI with card hover effects and animations
Responsive design for mobile and desktop
Built with Vite for fast development and optimized builds
State management with Redux Toolkit

**Tech Stack**
React
Typescript
Redux Toolkit 
Tailwind CSS

**Installation & Setup**
https://github.com/Senthamarai27/sky-music-app.git
cd sky-music-app
npm install
npm run dev
